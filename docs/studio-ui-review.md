# 工作台 UI 审核（2026-09-11）

## 修复范围

后台文章、专栏、成员与权限、我的资料四个页面。沿用主页暖白背景、细分隔线、衬线标题和墨绿色点缀。

原问题来自当前 JSX 与旧原型 CSS 的结构不一致：工作台标题、导航按钮、文章列表、编辑器分栏、表单缺少对应布局；成员列表的两个元素误用三列网格，姓名列被压到 25px。新增 `app/studio.module.css`，仅在工作台容器下生效。

- 统一页面宽度、间距、标题与表单比例，输入控件 16px，操作文字 14px。
- 工具栏与账号操作允许换行，长标题和成员名称可以自然折行。
- 手机端保留全部文章与专栏的横向切换，不再隐藏未选中项目。
- 编辑器提供写作、对照、预览视图；版本历史在文档流内展开并可以关闭。
- 创建作者补全标签，只有 Owner 显示创建入口；服务端权限检查保持原状。
